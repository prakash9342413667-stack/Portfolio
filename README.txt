PRAKASH N — PERSONAL PORTFOLIO
================================

CONTENTS
--------
index.html   Main website structure
style.css    Dark theme, responsive layout and visual styling
script.js    Mobile navigation, typing animation and current year
profile.jpg  Your profile photograph (included)

HOW TO PREVIEW
--------------
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser.
   Recommended: install the "Live Server" extension in VS Code, right-click
   index.html and choose "Open with Live Server".

ADD YOUR PROFILE PHOTO
----------------------
1. Choose a clear portrait photo of yourself.
2. Copy it into this same folder.
3. Rename the image to: profile.jpg
4. Refresh the browser.

The hero profile card will automatically show the PN initials until you add
profile.jpg. The same image is used in the profile card.

CUSTOMIZE
---------
- Edit your introduction, education, skills, project descriptions and email
  in index.html.
- Change colours, spacing and fonts in style.css.
- Change the rotating hero text in script.js.
- Add real GitHub / LinkedIn links when you are ready. No social URLs have
  been invented in this template.

PUBLISH FREE WITH GITHUB PAGES
------------------------------
1. Create a new public repository on GitHub, for example "prakash-portfolio".
2. Upload index.html, style.css, script.js and profile.jpg (if added).
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and /(root), then Save.
6. GitHub will provide your published website URL after deployment.

NOTES
-----
This is a static HTML/CSS/JavaScript portfolio. It does not require Python,
Flask, a database, or paid hosting. Project descriptions are written as
student learning-project summaries; update them to match the exact features
you have completed before publishing.


PROJECT STATUS & AUTO-LOADED PROJECTS
-------------------------------------
The "Live from GitHub" list loads your public repositories automatically.
Set each project's status on GitHub (only you can edit this):
  Repo page > gear icon next to "About" > Topics, then add one of:
    completed     -> shows "Complete"
    in-progress   -> shows "In Progress" (also the default when no topic is set)
    no-portfolio  -> hides that repo from your website
The repo's "Description" is shown as the project text.
Hand-written cards in "Selected work": edit the status text and class in
index.html (class "status in-progress" or "status complete").

UPDATE: the "Live from GitHub" list now shows ONLY completed repos.
Add the topic "completed" to a repo on GitHub when it is finished and it
will appear; repos without it stay hidden.

UPDATE 2: "Live from GitHub" shows ALL your public repos (except CP/practice-problem
repos) with a "Complete" badge. To mark one unfinished, add the topic "in-progress"
on GitHub; to hide one, add "no-portfolio".
